# Kheops

Vitrine e-commerce responsive avec un **film publicitaire animé** intégré à la page.

## Aperçu

Ouvrez `index.html` directement ou lancez :

```bash
python3 -m http.server 8000
```

## Contenu interactif

- Catalogue de produits avec filtres.
- Panier persistant dans le navigateur.
- Section campagne avec création graphique animée en 3 scènes.
- Lecture, pause et fermeture de la vidéo publicitaire via une fenêtre immersive.
- Mise en page responsive pour mobile et ordinateur.

## Personnalisation

Remplacez les produits et les URL Unsplash dans `app.js` avant une mise en ligne. La vidéo est une animation HTML/CSS de démonstration : aucun média vidéo externe ni droits tiers ne sont nécessaires. Connectez les formulaires à un backend avant d’accepter de vraies commandes.
